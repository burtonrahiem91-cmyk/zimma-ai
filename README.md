# ZIMMA

ZIMMA is a personal AI assistant for Windows, built by Rahiem Burton at Quiet Storm Studios.

## Download
Get the latest installer here:
https://github.com/burtonrahiem91-cmyk/zimma-ai/releases/latest

## How to install
1. Download ZIMMA-Setup.exe
2. Run it. If Windows says "Windows protected your PC", click More info, then Run anyway
3. Open ZIMMA from the Start menu

## Set up your API key (needed for cloud chat)
1. Open ZIMMA, go to Settings, then API Keys
2. Get a free Groq key at console.groq.com and paste it in
3. Optional: get a free Gemini key at aistudio.google.com
4. Click Save

Your keys are saved on your own computer. No key is needed if you only use local Ollama models.
